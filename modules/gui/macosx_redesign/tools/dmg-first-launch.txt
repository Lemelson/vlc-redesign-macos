VLC Redesign @VERSION@ for macOS 14 Sonoma or later (Apple silicon and Intel)

An unofficial build: a native macOS interface for VLC, made from Juxtopposed's
redesign, running VLC's unmodified engine. Not made by, affiliated with, or
endorsed by VideoLAN or Juxtopposed. "VLC" is a trademark of VideoLAN.

INSTALL
  1. Drag "VLC Redesign" onto "Applications".
  2. Eject the "VLC Redesign" disk (Finder sidebar, or drag it to the Trash).
  3. Open VLC Redesign from your Applications folder.
It is a separate app: if you also have VLC, it stays as it is.

FIRST LAUNCH
This build is not notarized by Apple, so macOS asks you to confirm it once.

macOS 14 Sonoma:
  Control-click (or right-click) VLC Redesign in Applications, choose Open,
  then click Open in the dialog.

macOS 15 Sequoia and later (Control-click > Open no longer skips the check):
  1. Open VLC Redesign. macOS says it could not verify the app: click Done.
  2. Open System Settings > Privacy & Security, scroll down to Security and
     click "Open Anyway" next to the message about VLC Redesign. The button is
     there for about an hour after step 1.
  3. Click "Open Anyway" in the dialog and enter your password.

Or, on any version, in Terminal:
  xattr -dr com.apple.quarantine "/Applications/VLC Redesign.app"

IF IT STILL DOES NOT OPEN
There is nothing else to install: the VLC engine, codecs and updater are all
inside the app. Make sure you have the latest version (1.0.0 and 1.0.1 asked
for macOS 27.2 by mistake; 1.0.2 fixed that). If it still fails, run this in
Terminal and paste the output into a bug report:
  sw_vers; uname -m; xattr "/Applications/VLC Redesign.app"
  defaults read "/Applications/VLC Redesign.app/Contents/Info" CFBundleShortVersionString
