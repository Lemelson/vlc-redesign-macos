## Flags and inconsistencies

- **Frames with no render:** none. **Renders with no frame:** none. `renders/styles.txt` is a text export of the styles, not a render.
- `Components.png` and `Designs.png` render the two giant canvas labels; they are not UI.
- `3336:11929` (`Add Subtitles to Playlist/Folder-1.png`) is an exact duplicate of `1911:7545` (same tree, geometry and text; pixel-identical render).
- Onboarding color frames `Onboarding-3 … -10` differ from `Onboarding-1` only in the accent color (identical geometry); they are not wired in the prototype.
- `Player - customize` frames embed a 1048×655 frame named "Add Subtitles to Playlist/Folder" that is actually the **Customize Player** dialog (copy-pasted dialog shell, never renamed).
- Settings → Extensions page title is **"Add-ons & Scripts"** in Figma, while spec-part2 §14 writes "Extensions & Scripts". Use the Figma text. Same page: list header "Add-ons", toggle "Load add-ons on startup".
- Settings → Video Advanced (`3073:15375`) contains "Time-shift buffer size", duplicated from Playback Advanced (copy-paste in the design).
- Settings → Interface has a typo "Show a popup when the track changew"; Settings → Recording has lower-case "include subtitles"; Privacy has two "Last.fm username" rows (the second is presumably "Last.fm password"; also in the video).
- Library texts contain the typo `The_Wand_S01E13mp4` (missing dot) in most frames; resume toast text "00:04:80" is an invalid time.
- `Player - Light` mixes Light and Dark styles (control-bar icons and library text still use Dark/FG/A2, Dark/FG/A1); see `../tokens/colors.json` meta.lightThemeCoverage.
- Node ids are identical across the three community copies used by the forks (figma keys `B7ifd32…`, `mNrr8…`, `fQSx…`); the srdouglax inventory lists 103 nodes (it omits the two text labels).
- The prototype wires some demo links that are not design intent (About VLC → Customize, right-click Playlist → Keyboard Shortcuts, key V → Add Subtitles, key F → Hide UI). See `../../research/from-forks/pyr0zen/FIGMA_FLOWS.md`.
