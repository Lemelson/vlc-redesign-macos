# redesign/

Everything specific to the macOS redesign lives here, plus the interface module
`modules/gui/macosx_redesign/`. Start with [`../AGENTS.md`](../AGENTS.md).

The local Codex implementation is documented in [`docs/CODEX_STATUS.md`](docs/CODEX_STATUS.md),
including the preserved Claude checkpoint, verified behavior and remaining
acceptance limits. [`docs/BUILD.md`](docs/BUILD.md) gives the isolated build paths.

- `docs/`: philosophy, decisions, plan, workflow, architecture, build, video breakdown.
- `design/`: the screen tracker (`SCREENS.md`), Figma data and renders, tokens, and specs.
- `research/`: community forks review (`FORKS.md`), deep analyses, and material copied from forks.
- `tools/`: helper scripts.

Credits: design by Juxtopposed (Figma, CC BY 4.0). Material in `research/from-forks/`
comes from the community forks listed in its README.
